# 静谧自然海报（轻量版）

把用户给的主题、配色或参考图，转换成可执行的 AI 出图方案：诗意标题 + 配色 + 构图 +
元素 + 材质光线 + 正向提示词 + 负向提示词 + 排版建议。**主题明确后默认交两版**：A 版标题
干净克制，B 版标题大胆飞扬。核心审美：低饱和自然意象 × 东方日系留白 × 胶片/纸张质感 ×
诗意但克制的文字。

## 第一步：读快查卡

- 高频表格与模板都在 [references/quick-cards.md](references/quick-cards.md)：色板库、情绪配色映射、
  **给定色的配色推演表**、模式叠加项、构图骨架、标题速查、提示词模板、检查清单。
- 简单请求可直接依据本文件工作；不确定时再查卡，**不要凭空发明新色板或新模式**。
- 找不到合适色板时，用第三步的推演法从任一种子色现场长一套，而不是硬套现有八组。

## 第二步：识别输入

从用户消息中提取以下字段，缺省项按默认规则补全：

| 字段 | 缺省时的处理 |
|---|---|
| 主题 | 必须有。宽泛主题先拓展成 4–6 个具象诗意方向供选择 |
| 配色 | 由主题情绪自动判断（见 quick-cards 的情绪映射表） |
| 强制文字 | 无则自动创作文案；有则逐字保留，不得改写 |
| 主元素 | 根据主题选一个自然意象，可从参考图显著元素提炼 |
| 叠加项 | 默认无。四个叠加项各自只改一个维度，每张最多叠两项；用户口语如「暗一点」「像杂志」映射到对应叠加项 |
| 画幅 | 默认竖版 2:3 |
| 参考图 | 先区分「稳定风格」与「图专属母题」，只吸收前者为规则 |
| 种子颜色 | 用户给出 hex/RGB/色号/中文色名/一段配色描述时，先进入**色板驱动模式**推演配色，再走工作流 |

「主题」与「种子颜色」至少有一个即可开工：只有颜色没有主题时**不要反问用户要主题**，直接反推方向并继续。

## 第三步：色板驱动模式（用户只给颜色时）

把「想要的颜色」当成**种子**而不是成品配色：它决定色相基因和情绪温度，但面积、明度层级、
饱和度都要按本体系的底线重排。六步走完再进第四步，细节查 quick-cards 的「给定色 → 配色推演」。

1. **解析归一**：所有输入色转 HSL 并记录用户原始 hex（交付时必须回显，用户要看自己的颜色去哪了）。
   中文色名按近似表取值并注明「近似，如不符请给 hex」。
2. **判角色**：按明度决定种子色当背景、中间调、深色还是强调色——`L≥70` 可做呼吸背景，
   `35<L<70` 做中间调，`L≤35` 只能做深色或字色（此时背景必须向同色相高亮另推）。别默认第一个色就是主色。
3. **收敛到画风**：饱和度压到 ≤45%（背景层 8%–25%）；四色明度阶梯每档拉开 ≥12；人工色相
   （正红、荧光、纯紫）向最近的自然色区间漂移 ≤15°；禁纯白纯黑，白转纸白、黑转深墨。
4. **补齐四色**：以种子为锚生成 纸白 / 中间调 / 深主色 / 强调色，给出面积占比（60–72 / 18–28 /
   6–15 / 3–8）。多色冲突（互补高饱和对撞）不硬碰：保留色相关系，把对比转移到明度与材质。
5. **反推主题**：用色相区间反查表得到 3–5 个主题方向（含主元素与构图骨架），**默认直接按推荐第一项
   出完整方案**，同时列出其余方向供换。
6. **命名**：给推演出的色板起 2–4 字中文名并标 hex，方便用户复用与口头指代。

**锁定优先**：用户说「就用这个颜色」「别改」「这是品牌色」时，该 hex 与强制文字同级——逐字保留、
不做柔化，改为调整其余三个衍生色、材质与明暗去成就它（通常把它降为 3%–8% 强调色，或压暗背景
让它沉住）。需要鲜艳就鲜艳，但面积必须小。

## 第四步：按工作流生成方案

1. **主题命名**：把功能性描述转成有画面、有余韵的诗意标题，如「夜晚独自整理自己」→
   「「我」的独处约会」。控制词藻密度：一个标题只保留一个核心意象和一个动作，不堆抽象形容词，
   不故作深沉。
2. **情绪定调**：先判断主题的季节感、温度、明暗和距离感，据此选主色板；强调色面积控制在
   3%–8%。色板驱动模式跳过选板，直接用第三步推演出的四色板，但明度层级与材质底线照旧执行。
3. **单一元素**：每张海报只有 1 个主元素 + 最多 2 个辅助元素 + 1 个光线焦点。参考图里的
   显著元素（海、蝴蝶等）要转成本画风后作为可替换主角。
4. **模式判断**：默认纯「安静自然」，不加叠加项。仅当主题或用户明确需要时叠加：编辑排版改版式、
   档案图鉴改信息结构、电影夜色改光色明暗、实验笔触改材质技法；每张最多两项，组合规则见
   quick-cards。向用户复述所选叠加项，避免静默改变风格。
5. **构图**：从六种骨架（中轴悬浮 / 上实下虚 / 对角线意象 / 低位地平线 / 偏侧留白 /
   小人物远景）中选一种；留白区保持 25% 以上。
6. **文字排版（双版）**：主标题 2–8 字，副句 8–24 字，英文辅助 1–4 词；字距疏朗；预留干净的
   后期排版区。按 quick-cards 的「标题设计速查」选方案，默认无色块衬底、无描边、无发光。
   **默认同时给两版**：A 版克制（细宋 + 留白嵌字/上下锚点/沿结构线生长 + 白字压暗部），
   B 版飞扬（手写行楷或书法大字 + 长笔画贯穿/大小对比/散点呼吸 + 同色系或强调色跳出）；两版
   **主色与主题必须一致**，标题三项必改；主元素、构图、光线焦点可各自取最优解，不强行相同。
   用户只要一版时只出一版。默认不要求模型生成可读中文——图像模型生成的中文不可靠且无法证明字体授权。
7. **字体版权**：提示词只描述字体气质（细宋体气质、现代衬线体、克制手写笔触）；正式发布用
   已确认授权的开源字体（思源宋体/黑体、Noto 系列）后期重排。绝不把未授权商业字体名写进提示词。
8. **组装提示词**：按 quick-cards 的模板为 A/B 两版各组装一份正向提示词（同一模板填两次：主色与
   主题一致，标题三项必改，其余按各自最优），注明所加叠加项；负向提示词默认附上并两版共用。
9. **自检**：交付前过一遍 quick-cards 里的检查清单（含双版一致性一项）；不过关就先修再交。

## 输出格式

每次交付包含：

- **主题方向**：若主题宽泛，先给 4–6 个诗意方向（含场景说明），等用户选定；
- **定稿信息**：主题名、配色（含 hex，两版必须一致）、模式、画幅；主元素与构图骨架分别标出（A/B 可各自最优）；
- **配色推演表**（色板驱动模式必给）：四行——色名 / 角色与占比 / hex / 与用户原色的关系
  （如「S 50→22，L 53→72，H 不变」），并单列一行回显用户的原始 hex；被锁定的色标注「原色未改」；
- **文案**：主标题 + 2–3 条原创副句候选 + 可选英文辅助；
- **A 版（克制）正向提示词**：完整可用的代码块，标注所选骨架/字体/字色；
- **B 版（飞扬）正向提示词**：同上，主色与 A 版一致，标题气质更外放，元素可按需换得更有动势；
- **负向提示词**：两版共用，一个代码块；
- **排版建议**：文字位置、横竖排、断行，以及两版的差异说明（一句话说清各自适合什么场景）。

## 边界情况

- **用户给了强制文字**：优先级最高，逐字保留包括标点和换行；只能调整字体、字号、颜色、位置；
  A/B 两版都必须完整嵌入同一串强制文字。
- **用户只要单版**：说「只要一版」「只要克制版」「只要飞扬版」时按他说的来，不额外补另一版。
- **图像生成工具不可用**：照常交付完整方案与提示词，明确说明出图失败的原因（如权限），不要
  静默跳过。
- **用户只要底图**：输出无字模板变体，强调保留空白排版区。
- **系列化请求**：固定配色逻辑、材质、字体层级和留白习惯，只轮换主元素；默认输出核心版 +
  2 个同画风变体。
- **主题含义模糊**：以雾森青 + 米白为基础方案，再向冷蓝/灰粉/麦芽色偏移，并主动向用户确认方向。
- **只给颜色、没给主题**：不追问，按色相反查表给 3–5 个方向，先按推荐项出完整方案。
- **给的颜色太鲜艳**：默认柔化并在推演表里写明改了什么；同时保留一句「要原色就把这套色板换回
  你的 hex，但面积压到 5% 以内」。
- **给的颜色互相打架**（正红×正绿、荧光×粉）：给两版说明——一版按体系收敛、一版原样保留但
  重排面积与明度，让用户选，不擅自判「这颜色做不了安静感」。
- **出图后颜色被模型拉艳**（最常见失败）：二次收敛重跑——把 hex 从「主色」降级为「氛围色」，
  追加 `matte finish, halved saturation, fog-washed, low contrast`，并强调纸张与颗粒。有识图通道时
  先核对成图主色是否偏离再决定重跑。
