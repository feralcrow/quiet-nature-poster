## 给定色 → 配色推演（色板驱动模式）

用户只给颜色时的完整流程：把“想要的颜色”当**种子**（定色相基因与情绪温度），不当成品配色。
目标是从一到几个种子色长出四色板，再反推主题。

### 1 中文色名近似取值

只给了色名没给 hex 时先按此取值，并在交付里注明“近似，如不符请给 hex”。

| 雾蓝 | `#7D99A3` | 196° 17% 56% | 冷色中间调 |
| 青瓷/天青 | `#A8C4BE` | 167° 19% 71% | 清透冷绿系（自推） |
| 豆沙 | `#C08A85` | 5° 32% 64% | 远山灰粉系 |
| 藕荷 | `#D9C5C1` | 10° 24% 80% | 春雾花野系 |
| 墨绿 | `#243126` | 129° 8% 17% | 绿意微距深色 |
| 苔绿 | `#87947A` | 90° 11% 53% | 米纸蕉叶系 |
| 麦芽 | `#D3B98B` | 38° 45% 69% | 秋日麦光系 |
| 琥珀 | `#AE8550` | 34° 37% 50% | 秋日麦光强调 |
| 砖红/铁锈 | `#A85751` | 5° 35% 49% | 暖褐深色（近秋日麦光） |
| 靛蓝/群青 | `#354664` | 218° 31% 30% | 深夜靛蓝系 |
| 纸白/牙白 | `#F1EDE3` | 43° 33% 92% | 可直接当背景 |

注：墨绿、群青这类深色 L 均 ≤ 30，按第 2 条只能做深色/字色，不能直接当背景。

### 2 种子色判角色（看明度，不看给的顺序）

| 种子 L | 可当 | 处理 |
|---|---|---|
| ≥ 70 | 呼吸背景 / 大面积主色 | 饱和度按背景层压到 8%–25%，必须另配一个深色做字与重心 |
| 35–70 | 中间调 / 辅助色 | 单独给色时，背景需自己向上推一个纸白（L 92±3） |
| ≤ 35 | 深色 / 字色 | 不能当背景；同色相向上提 L≥88 做底，或叠「电影夜色」整体压暗 |

### 3 收敛参数（一次算完，别多轮试）

- **S**：背景 8–25｜辅助 15–32｜深主色 18–30｜强调可放到 42–60（面积 ≤8%）。原色 S>60 统一 −25~−40。
- **L 阶梯**：四色 L 依次约 `93±3 / 72±6 / 32±8 / 与深主色差 ≥15`；任意两色 L 差 <10 → 其一 ±15。
- **H**：允许 ±6° 漂移。正红/正绿/正蓝（0、120、240）与荧光色拉向最近的自然色区间 10–20°；
  紫（270–300）往 262 或 315 拉，不然会塑料。
- **黑白**：白不用纯白，转带色相的纸白（`#F1EDE3`–`#F3F5F6`）；黑不用纯黑，转深墨（`#202B3A`、`#243126`、`#1F2B1E`）。
- **雾感**：L>75 的浅色统一再 L+3、S−3，做空气层。这一步决定画面有没有“呼”出来。

### 4 四色板组装模板

```text
纸白    #______  H__ S__ L__   60%–72%   背景与留白
中间调  #______  H__ S__ L__   18%–28%   雾、虚化主体、次要结构
深主色  #______  H__ S__ L__    6%–15%   标题字、构图重心
强调色  #______  H__ S__ L__    3%–8%    一处光点 / 印章 / 花心
```

每个色都要回显与用户原色的关系（例：“S 50→22、L 53→72、H 不变”），并单独列出用户原始 hex。

### 6 冲突与锁定

| 情形 | 处理 |
|---|---|
| 互补高饱和对撞（红×绿、橙×蓝） | 保留色相关系，二者之一降 S 到 12–18 转灰调中间调，另一个只留 ≤5%；对比交给明度与材质 |
| 几个色明度全挤在中段 | 最亮的提到 L92 当纸白，最深的压到 L28 当重心 |
| 全是低对比邻近色 | 允许强调色跳出（同色系里最艳的一个），或叠「档案图鉴」用信息层级补差 |
| 颜色数 > 4 | 取前四个，其余只进材质与光线（如“一点金属反光”） |
| 用户说“别改”/品牌色 | 该 hex 逐字锁定，其余三色向它的邻色或纸色生成；需要时压暗背景让亮色沉住 |

### 7 完整示例

**输入**：`#C24A5B`（偏艳玫瑰红，无其他信息）。解析：H352 S50 L53 → 当**中间调**；H 已在灰粉区间，主要降 S、提 L。

| 色名 | hex | 角色与占比 | 与原色的关系 |
|---|---|---|---|
| 粉雾纸白 | `#F3F1F2` | 背景 62% | 由种子色相派生，S8 L95 |
| 豆沙中间调 | `#C7A8AC` | 辅助 24% | 原色 S50→22、L53→72、H 不变 |
| 深酒栗 | `#6F3E47` | 深色 10% | 同 H，S28 L34 |
| 跳朱 | `#B85166` | 强调 4% | S 提到 42（强调色下限），只给一处花心或印章 |

反推主题（H352 → 花期/告别/心事）：首选「落在肩上的春末」（主标题用两到四字：春末／落肩，副句补全），主元素一枝失焦芍药，偏侧留白；
备选：寄不出的信／梅雨刚停／一个人的花期。

**同一颗种子、用户说“就要这个红，别改”**：锁定 `#C24A5B` 做 4% 强调色，其余全部改就它——
纸白 `#EFEDEB` 62%、暖灰褐 `#BDAFA8` 24%、深栗 `#4A2629` 10%。鲜艳不再靠饱和度，靠面积对比。

### 8 出图二次收敛短语

模型最爱干的事就是把 pastel 拉成 vivid。颜色跑艳时把 hex 从“主色”降为“氛围基调”，并追加：

```text
matte finish, halved saturation, fog-washed pastel, muted dusty tones, low contrast, paper grain, no neon, no vivid pigment
```

## 模式体系（一个基础 + 四个可叠加项）

**基础底色（永远生效）：安静自然**

- 所有海报的共同底层：低饱和、柔焦、大面积留白、轻颗粒、一个主元素、克制文字。不加任何叠加项时，就是最初的谧静自然风格。

**四个可叠加项**（每张最多同时两项；表述写作「安静自然 + 叠加项」）

| 叠加项 | 只改什么 | 加进来会怎样 | 什么时候用 | 触发词示例 |
|---|---|---|---|---|
| 编辑排版 | 版式 | 超大标题、双层画廊结构、细英文基线，更像杂志内页 | 节气专题、品牌月报、系列封面 | 杂志感、标题大一点 |
| 档案图鉴 | 信息结构 | 编号、年份、圆形视窗、图注小字，像标本卡 | 图鉴、研究记录、展览、文创 | 档案、图鉴、编号 |
| 电影夜色 | 光色与明暗 | 整体变深蓝/深绿，暗部颗粒更厚，主体压到低位 | 雨夜、告别、孤独、冬季 | 夜、电影感、暗一点 |
| 实验笔触 | 材质技法 | 刮板颜料、透明叠层、套印偏移，或青柠强调色 | 抽象季节、先锋编辑、当代艺术 | 抽象、实验、颜料 |

组合规则：默认只开基础，不叠；每张最多叠 1–2 项，叠得越多离「安静」越远；推荐「档案图鉴 × 电影夜色」「实验笔触 × 编辑排版」，慎用「档案图鉴 × 实验笔触」。

同一主题下的效果差异（以「霜降」为例）：仅基础 = 雾白雪坡 + 细树影；+编辑排版 = 超大「霜降」压在下方留白处；+电影夜色 = 整体沉入深蓝暮色，树线压到低位。

## 构图骨架

| 骨架 | 做法 | 适合 |
|---|---|---|
| 中轴悬浮 | 背景虚化，标题居中，副文案少量分布 | 春夏、节气、生活方式 |
| 上实下虚 | 上方意象块，下方大面积留白放字 | 生长、寻找方向、秋日 |
| 对角线意象 | 叶/枝/水纹斜穿画面，标题沿空白布置 | 风、雨、迁徙、旅行 |
| 低位地平线 | 地平线在下 1/3，天空占大面积 | 海、远方、告别、自由 |
| 偏侧留白 | 主体占一侧 1/3，另一侧完整呼吸区 | 花、枝叶、品牌 |
| 小人物远景 | 人物极小作比例尺，置于大空间 | 独处、夜晚、回家、等待 |

口诀：先找呼吸区，再放主意象；先定情绪重心，再放标题；宁可空三分，不要满到没有回声。

## 标题设计速查

总原则：无色块衬底、无描边、无发光、无投影；可读性靠画面明暗、同色系和留白。

| 排版骨架 | 做法 | 适用 |
|---|---|---|
| 阶梯错落（最常用） | 行首行尾不对齐，沿对角线逐行下沉，基线微倾 | 诗句式标题、情绪主题 |
| 大小对比 | 一行小字 + 一个核心大字（高 1/4–1/3）或首字放大 | 单字点题 |
| 长笔画贯穿 | 长横长撇拉长出画；书法大字末笔垂落贯穿画面 | 书法、风、动势 |
| 竖排右行 | 竖排右对齐，英文横排小字缀底 | 东方、节气、山水 |
| 中英咬合 | 英文小字嵌行间或低透明度叠印 | 双语海报 |
| 留白嵌字 | 标题整体放负空间，零叠压 | 极简高留白 |
| 沿结构线生长 | 文案顺花茎/枝条/地平线排布，小字大距分级 | 节气、主体特写 |
| 主体当立轴 | 树干/光柱作贯穿轴，文字悬挂两侧 | 单主体极简、禅意 |
| 散点呼吸 | slogan 拆成中英小短语对角线散钉 | 禅意、生活方式 |
| 上下锚点 | 顶部拼音拉开+底部英文收尾，中央嵌字 | 节气三明治 |
| 日历信息组 | 大字星期+((年))+长横线牵引日期，字色随区反转 | 日系、旅行、日记 |

字体气质三选一：细宋（横细竖粗、Light、衬角锐利）｜手写行楷/瘦金（连笔、飞白、笔画拉长）｜毛笔书法大字（只用于单字或超大主字）。西文：Didot 类高对比衬线、衬线斜体、花体首字母。

字色策略三选一（代替底色）：白字压暗部（明度对比）｜主色深一档同色系（深苔绿/玫红/金/墨绿）｜深灰墨字放浅色负空间。

融合手法：直接叠加靠暗部｜英文 30%–60% 透明度叠印半溶｜字边缘被雾气轻咬｜零叠压嵌字｜同色勾线沿山势呼应字迹｜手写长拖笔方向=画面动势（字势即景势）｜实物小图嵌句中当活字｜文字落在褶皱布面侧光里｜拟声词字号渐隐斜排｜假名/符号插入标题作顿挫。标题避开几何正中，占宽 50%–80%；单字约画面宽 1/10，核心大字可到 1/4 以上。

```text
onomatopoeia fading in size along a diagonal
```

选择逻辑：书法/手写→情绪浓的个人化主题；细宋→节气、自然观察、安静知性；大小对比/长笔画→单字点题。每张只选 1 骨架 + 1 字体 + 1 字色策略。

## 双版标题输出（克制版 × 飞扬版）

主题明确后，**默认同时交两版**方案，让用户直接对比挑选：

| | A 版·干净克制 | B 版·大胆飞扬 |
|---|---|---|
| 标题骨架 | 留白嵌字 / 上下锚点 / 沿结构线生长 | 长笔画贯穿 / 大小对比 / 散点呼吸 / 主体当立轴 |
| 字体气质 | 细宋（Light、横细竖粗、衬角锐利） | 手写行楷/瘦金，或毛笔书法大字 |
| 字色策略 | 白字压暗部，或深灰墨字放负空间 | 同色系呼应，或允许强调色跳出 |
| 融合手法 | 零叠压嵌字、靠暗部直接叠加 | 字势即景势、勾线呼应、实物活字、声音渐隐 |
| 字号尺度 | 标题占宽 40%–60% | 标题占宽 60%–90%，单字可放大到画面高 1/4 |
| 主元素 | 偏静：一叶、一窗、一束光、静止水面 | 偏动：风、水波焦散、兽群剪影、悬滴细线 |
| 情绪 | 安静、退一步、耐看 | 有动势、情绪外露、第一眼抓人 |

规则：两版**主色与主题必须一致**（同色板、同强调色面积），方便对比与后续系列化；标题三项（骨架/字体/字色）必改；主元素、构图、光线焦点、材质强度**都允许按各自风格取最优解**，不必机械相同——目标是两版各自都是好画面。各给一份完整正向提示词，负向提示词共用；强制文字两版都逐字保留。叠加项默认一致，B 版确实需要更强动势时允许不同但须写明；结构化模式下 B 版的大胆体现在尺度与错落，不加高饱和不加强装饰。用户说“只要一版/只要克制版/只要飞扬版”时只出一版。

## 常用元素速查

蕉叶/大叶片、细枝、模糊花影、草地、海平线/水面、飞鸟（2–5 只小剪影）、光晕、雾/薄纱、
树影、小人物背影、月亮/太阳、水纹/风纹、纸张纤维、印章小符号、蝴蝶/蛾（幽光处理）、
茶器（配运动模糊）、湿窗雨痕、悬滴细线、颗粒立轴、水波焦散、白布载体、兽群剪影。

每张限用：1 主元素 + 0–2 辅助元素 + 1 种主笔触 + 1 个光线焦点 + 1 组配色。
元素可系列化轮换：固定风格系统，只换主角（如大海→海平线→水纹→潮痕）。

## 交付前检查清单

- [ ] 只有一个清晰的主意象？
- [ ] 至少 1/3 呼吸空间？
- [ ] 主色低饱和不刺眼？
- [ ] 有一个自然柔和的光线焦点？
- [ ] 主体边缘足够柔？
- [ ] 有颗粒/纸张/雾感但不过度滤镜？
- [ ] 文字区干净，后期排版有空间？
- [ ] 字体不超过三种且授权清晰？字距疏朗？
- [ ] 无商业广告、电商主图、信息堆叠？
- [ ] 先感到情绪，再看懂主题？
- [ ] 双版输出时：主色是否一致？两版是否各自都是最优解？
- [ ] 色板驱动时：是否回显了用户原始 hex，并写清每个色的改动原因（或标明“原色未改”）？

最终判断：删掉一半元素更好看就删；颜色漂亮但没有空气感就降饱和；主体清楚但没有情绪就加雾、
加距离、加留白；文字抢过意象就把字变轻变小变疏。
